# TaskFlow — Gerenciador de Tarefas

Aplicação web para organização de tarefas pessoais, desenvolvida
com HTML5, CSS3 e JavaScript puro.

## Sobre o projeto

O TaskFlow permite cadastrar, editar, pesquisar e acompanhar tarefas
em uma interface moderna e responsiva.

O projeto foi criado para praticar desenvolvimento front-end,
manipulação do DOM, eventos JavaScript e armazenamento local.

## Funcionalidades

- Cadastro de tarefas com título e descrição.
- Definição de prioridade baixa, média ou alta.
- Definição de prazo para conclusão.
- Edição e exclusão de tarefas.
- Marcação de tarefas como concluídas.
- Filtros de tarefas por situação.
- Pesquisa por título ou descrição.
- Indicadores de tarefas totais, pendentes e concluídas.
- Remoção de tarefas concluídas.
- Persistência dos dados com LocalStorage.
- Interface responsiva para computador e celular.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API
- Git e GitHub

## Como executar

1. Clone este repositório:

   git clone https://github.com/SEU-USUARIO/taskflow-gerenciador-tarefas.git

2. Entre na pasta do projeto:

   cd taskflow-gerenciador-tarefas

3. Abra o arquivo index.html no navegador.

Não é necessário instalar dependências.

## Armazenamento

As tarefas são salvas no LocalStorage do navegador.
Por isso, os dados ficam disponíveis no mesmo navegador e
perfil utilizados para cadastrar as tarefas.

O projeto não utiliza servidor ou banco de dados compartilhado.
